2. Trigger a Payment

Execute a payment from the Python Agent SDK:

📊 Architecture Overview

Zone 0 (Untrusted): Python FastAPI Agent SDK signing payments with raw-byte HMAC

Zone 1 (Core Authority): Java Spring Boot Payment Switch with MariaDB durability + Redis acceleration

Zone 2 (Control Plane): Angular Dashboard with pessimistic mandate revocation
