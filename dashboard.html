📚 Documentation & Code

Architecture & Design:

  • Phase 1: HLD architecture with SLA budgets and threat model
  • Phase 2: Data models with double-entry ledger and generated columns
  • Phase 3: Backend LLD with raw-byte HMAC, two-phase velocity, pessimistic locking
  • Phase 4: Python agent with strict Pydantic and idempotency key lifecycle
  • Phase 5: Angular UI with RxJS streams and pessimistic revocation

All code is in https://github.com/5andeepNambiar/AgenticUPI

🎯 Key Technical Highlights

  • Raw-Byte HMAC-SHA256: Exact HTTP body signing prevents JSON canonicalization bugs across Java/Python integration
  • Two-Phase Velocity: Redis Lua + DB transaction + post-commit hooks = durability without permanent quota loss
  • Idempotency Key Lifecycle: UUID generated once BEFORE retry loop prevents double-debits on timeouts
  • Claim-Publish-Ack Outbox: FOR UPDATE SKIP LOCKED releases DB locks before Kafka publish, enables horizontal scaling to 10K TPS
  • Pessimistic Mandate Kill-Switch: DB revocation first, then Redis tombstone. If cache is down, DB still blocks payments
